# CSP QuickLearn 🧩

Built this while prepping for my AI exam because reading about Constraint Satisfaction Problems for the 5th time wasn't making it click — so I made a tiny interactive site that explains CSP concepts like variables, domains, constraints, and backtracking using Sudoku as the example, complete with a real step-by-step backtracking solver you can actually watch in action. No login, no backend, just open `csp-quicklearn.html` in your browser and you're good to go.

🔗 **Live:** [ankit-stack-glitch.github.io/csp-quicklearn](https://ankit-stack-glitch.github.io/csp-quicklearn/)
