Pseudocode

BACKTRACK(assignment):
    if assignment is complete:
        return assignment

    variable = select an unassigned variable

    for each value in the domain:
        if value is consistent:
            assign value
            result = BACKTRACK(assignment)

            if result is successful:
                return result

            remove assignment

    return failure

Backtracking means trying a possible assignment and undoing it when it leads to a violation, then trying the next option.
